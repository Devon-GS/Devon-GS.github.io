## 💻 Tech Stack & Site Architecture

This static portfolio is built to be fast, responsive, and aesthetically pleasing using modern web technologies:

* **Markup & Styling**: HTML5, CSS3
* **Framework**: [Bootstrap v5.2.3](https://getbootstrap.com/)
* **Interactivity & Animations**: 
  * `Typed.js` for the hero section typewriter effect.
  * `Swiper.js` for smooth service sliders.
  * `Isotope` for seamless portfolio filtering and layout.
  * `GLightbox` for image popups.
* **Form Handling**: Contact form powered by [Formspree](https://formspree.io/).
* **Icons**: Bootstrap Icons & Boxicons.
* **Typography**: Google Fonts (Poppins & Playfair Display).
